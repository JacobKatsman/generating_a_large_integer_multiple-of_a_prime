Для простого проекта (один пакет):

    Перейдите в директорию: Откройте терминал и перейдите в папку, где должен располагаться ваш новый проект, 
	например, cd my-haskell-project.
    Инициализация: Выполните команду cabal init. 
	Cabal задаст вам несколько вопросов о названии проекта, авторе, лицензии и т.д., 
	чтобы создать файл my-haskell-project.cabal.
    Сборка: Для компиляции проекта используйте cabal build.
    Запуск: Если это исполняемая программа, запустите ее командой cabal run.
